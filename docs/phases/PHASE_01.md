# Phase 01 — Cinematic landing foundation

## Goal
Build a responsive, polished landing page with a clear path into exploration.

## Tasks
1. Implement or refine the page shell, navigation, hero content, typography, layout, CTA, and control hints.
2. Use a cinematic Dravidian temple visual direction: stone/earth palette, warm highlights, restrained atmosphere, strong composition.
3. Use a local poster/placeholder until the real model is integrated. Avoid unlicensed imagery.
4. Implement functional CTA state/transition and responsive navigation. No inert buttons.
5. Provide loading and error UI primitives suitable for Phase 02.
6. Add keyboard focus, accessible names, and reduced-motion support.
7. Verify wide and narrow layouts.

## Constraints
Preserve existing conventions. Avoid unnecessary libraries, fake loading progress, and decorative clutter.

## Acceptance
- [ ] Landing page responsive at desktop and mobile widths.
- [ ] CTA has real behavior.
- [ ] Placeholder is clearly replaceable by the 3D Canvas.
- [ ] UI is keyboard navigable and focus is visible.
- [ ] Existing lint/type/build checks pass, or failures are documented with evidence.
